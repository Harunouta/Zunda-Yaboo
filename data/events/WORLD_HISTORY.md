# 世界史イベント（疎）— 設計メモ

日本ノード向け。**フル世界史年表ではない。**  
「その月、交易・貴金属・砂糖・原油・疫病・安全保障の噂が統治／庶民に効くか？」で切っている。

## ファイル

| ファイル | 役割 |
|----------|------|
| `world/catalog.yaml` | 定義（prompt / worldEffect / 疫病係数） |
| `world/timeline.csv` | 世界側の発生月 |
| `bridges/japan_from_world.csv` | 長崎・市況ラグでの再発火（同じ eventId） |

日本国内史は `japan/*`（日本側イベントの主データ）。世界側と月が重なってもよい（例: 1929-10 に `great_depression` + `wall_street_crash`）。

## 既存 worldEffect の使い分け

| 効果 | 典型 |
|------|------|
| `sugar_spike` | 砂糖・綿花・航路寸断 |
| `gold_outflow` | 銀／金／恐慌・資本逃走 |
| `oil_spike` | 原油・エネルギー危機 |
| （効果なし） | 秩序転換・独立・運河開通など情報ショック |

`hyperinflation` / `han_satsu_crisis` は主に国内イベント用。世界側では使っていない。

## カバレッジ方針

- 17c: 銀・明清交代・VOC／英蘭・台湾・継承戦争入口
- 18c: 泡沫・継承戦争・七年戦争・独立・ハイチ砂糖・大陸封鎖
- 19c: アヘン戦争・金鉱・スエズ・綿花・1873恐慌・米西戦争
- 20–21c: 流感・ヴェルサイユ・ウォール街・ポンド危機・大戦・ブレトン／スエズ／ベトナム／OPEC／アジア危機／リーマン／COVID入口／ウクライナ
- **2020→2026-08**: ロックダウン、半導体不足、欧州ガス、ChatGPT/GPU、紅海・中東・ナフサ、AI投資競争、輸出規制、期末マーカー `sim_horizon_2026_08`

概数（2026-08-21）: world catalog ≈56、発火月（origin+bridge）は 17–21c に疎く分散。`python scripts/summarize_events.py --scope world` で確認。

追加するときも「日本の物価・噂・備蓄に月次で効くか」を先に自問すること。
