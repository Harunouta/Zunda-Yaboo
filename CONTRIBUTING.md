# Contributing (when the repo goes public)

1. Do **not** commit anything under `data/restricted/` except its README.
2. Do **not** commit `logs/`, `checkpoints/`, or model weights.
3. Read [REDISTRIBUTION.md](REDISTRIBUTION.md) before adding new datasets.
4. Prefer synthetic / original samples in `data/redistributable/`.
5. GitHub remote setup is owned by the maintainer; contributors need not configure it.
